# Elfren James C. Coopera — Deployed Portfolio Website

A clean, minimalist, professional three-page portfolio built for the Continuous Project assignment.

## Pages
- `index.html` — Home
- `skills.html` — Skills Inventory
- `career-goals.html` — Career Goals Portfolio

## Before deployment
1. Replace the email and LinkedIn placeholders on `career-goals.html`.
2. Open `index.html` locally to preview.
3. Deploy the folder using GitHub Pages, Netlify, or Vercel.
4. Submit the resulting live URL.

The website follows the assignment requirements: consistent navigation, responsive layout, professional typography, a 5-level proficiency scale, skill context/examples, skill gaps, short/mid/long-term goals, preferred domain, skill development plan, motivation/values, and contact information placeholders.
