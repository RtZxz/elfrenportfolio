DueBuddy – Bill Reminder Mobile Application

Role: Android Developer / Project Developer

Problem:
Many users forget payment deadlines, resulting in missed bills and late payments. DueBuddy was developed to help users organize and monitor recurring expenses.

Technologies Used:
Android Studio, Java/Kotlin, SQLite Database, XML

Key Contributions:
Designed application screens, created database structure, and developed bill tracking features.

Outcome:
Created a functional mobile application prototype that helps users manage their monthly bills.
